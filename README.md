Small pfSense utility written in Python that will print Wifi Vouchers to a esc/POS thermal printer.

Go to PfSense webGUI/Captive Portal and create Wifi Voucher rolls and download those rolls to your desktop computer. Double-click on WifiVouchers.exe then click on import roll and select the roll you downloaded from webGUI/Captive Portal. You can now start to print voucher codes to your standard esc/POS thermal printer. A messagebox will prompt you to confirm the voucher printed successfully. Clicking YES will mark the voucher code as expired and a new voucher code will be printed next time. Clicking CANCEL will not mark the voucher code expired but instead allow you to re-print the last voucher number again (in case of paper jam etc.).

Pre-requisites: The INI file must be present in the current directory (a sample INI will be created if one doesn't exist). The name of the printer in the INI file must match the name of the esc/POS printer listed in the Windows Printer & scanners list. The server_address is the IP address or resolvable DNS name of your pfSense firewall (e.g. 192.168.1.1 or pfsense.mycafe.com), the captive portal zone_name, the URL_scheme (either http or https). Note that self-signed certificates should not be used if the URL_scheme is set to HTTPS otherwise guests will receive SSL certificate errors and the QR code may fail to register users into the Captive Portal.

Additional Notes:
You can import multiple fresh voucher rolls into WifiVouchers. Each voucher roll generated by pfSense can have a maximum of 65,553 codes and multiple voucher rolls can be active at once on the pfSense captive portal. If you create multiple voucher rolls in pfSense for import into WifiVouchers all rolls should be configured with the same user rate and time limits for consistency.

If you find a situation where voucher codes in WifiVouchers database and the pfsense captive portal are unsynchronized simply exit WifiVouchers and delete the vouchers.db then when you next run WifiVouchers it will create an empty vouchers.db then import fresh new rolls from Captive Portal.

To compact the database set the compact_database in the INI file to true and the next time you start WifiVouchers.exe it will compact the database once and set the INI value back to false.

WifiVouchers has been compiled for Windows 32-bit and should work for all Windows versions 7/8/10/11 both 32/64 bit.


Linux notes:
To run on Linux desktop (64-bit) you need to have all required python libraries pre-installed. Go to the directory of WifiVouchers then: pip install -r requirements.txt

When installing printer types in Linux choose GENERIC then RAW QUEUE for generic esc/POS thermal printers and make sure your port selection is correct eg. USB001.

To run from a bash terminal change to the directory and type: python -m WifiVouchers
