Small pfSense utility written in Python32 that will print Wifi Vouchers to a esc/POS thermal printer.

Go to PfSense webGUI/Captive Portal and create Wifi Voucher rolls and download them to your desktop computer. Double-click on WifiVouchers.exe then click on import roll and select the roll you downloaded from pfSense. You can now start to print voucher codes to your standard esc/POS thermal printer. A messagebox will prompt you to confirm the voucher printed successfully. Clicking YES will delete the voucher number from the database and a new voucher code will be printed next time. Clicking CANCEL will not delete the voucher code from the database but instead allow you to re-print the last voucher number again (in case of paper jam etc.).

Pre-requisites: The INI file must be present in the current directory (a sample INI will be created if one doesn't already exist). The name of the printer in the INI file must match the name of the esc/POS printer listed in the Windows Printer & scanners list. The server_address is the IP address or resolvable DNS name of your pfSense firewall (e.g. 192.168.1.1 or pfsense.mycafe.com), the captive portal zone_name, the URL_scheme (either http or https). Note that self-signed certificates should not be used if the URL_scheme is set to HTTPS otherwise guests will receive SSL certificate errors.

Additional Notes:

You can import multiple fresh voucher rolls into WifiVouchers. Each voucher roll generated by pfSense can have a maximum of 65,553 codes while allowing for multiple voucher rolls to be active on the pfSense captive portal. If you create multiple voucher rolls in pfSense for import into WifiVouchers all rolls should be configured with the same user rate and time limits for consistency.

To compact the database set the compact_database in the INI file to true and the next time you start WifiVouchers.exe it will compact the database once and set the INI value back to false.
